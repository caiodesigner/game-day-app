# Local sound effects

Original synthesized tones generated by `scripts/generate_sounds.py` for this
project. No third-party recordings or samples are used. Regenerate with:

```bash
python3 scripts/generate_sounds.py
```

PCM WAV, mono, 22,050 Hz, 16 bits:

- `place.wav`: short placement tone.
- `clear.wav`: ascending line-clear chime.
- `gameOver.wav`: descending end-of-game tone.

These files are bundled with the app and require no network access.
